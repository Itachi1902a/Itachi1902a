## `03` · Proyectos destacados

### 🎮 Gamertag — Catálogo y administración de videojuegos

Aplicación web académica para consultar y administrar un catálogo de videojuegos.

- Backend con Node.js y Express.
- Base de datos MySQL.
- Autenticación mediante sesiones y contraseñas cifradas.
- Roles de usuario y administrador.
- Gestión de videojuegos, imágenes y comentarios.

**Tecnologías:** JavaScript · Node.js · Express · MySQL · HTML · CSS

[Consultar mis repositorios](https://github.com/Itachi1902a?tab=repositories)

### 📱 Bitácora Digital de Administración de Redes — Proyecto colaborativo

Aplicación multiplataforma desarrollada en equipo para administrar redes, subredes, dispositivos e incidencias.

- Proyecto académico colaborativo de cinco integrantes.
- Gestión de redes, subredes y dispositivos.
- Registro y seguimiento de incidentes y mantenimientos.
- Generación de reportes PDF.
- Validaciones de direcciones IPv4 y MAC.
- Mapas y localización de infraestructura.

**Mi participación:** colaboración en el desarrollo del proyecto y trabajo coordinado mediante Git y GitHub. Consulta el repositorio del equipo para conocer el alcance y las contribuciones compartidas.

**Tecnologías:** React Native · Expo · TypeScript · InsForge · PostgreSQL

[Repositorio del equipo](https://github.com/EduardoRivas25/Bitacora-movil) · [Aplicación web](https://bitacora-movil.vercel.app/)

### 🤖 Robot Mini Sumo — Robótica y control

Prototipo de robot mini sumo con modos de funcionamiento autónomo y control remoto.

- Arduino Nano como unidad de control.
- Driver de motores TB6612FNG.
- Sensores ultrasónicos para detectar al oponente.
- Sensor de línea para reconocer el límite del dohyo.
- Comunicación Bluetooth mediante HC-05.

**Tecnologías:** Arduino · Electrónica · Sensores · Bluetooth · C/C++

[Consultar mis repositorios](https://github.com/Itachi1902a?tab=repositories)

---

### 🏎️ Robot seguidor de línea — Sistemas embebidos

Diseño de un robot móvil para detectar y seguir una trayectoria mediante sensores reflectivos.

- Arduino Nano.
- Arreglo de ocho sensores QTR.
- Driver TB6612FNG.
- Dos motores N20 con reductora.
- Alimentación mediante batería LiPo 2S.
- Diseño de chasis y planificación de PCB.

**Tecnologías:** Arduino · Sensores QTR · Electrónica · Diseño de PCB

[Consultar mis repositorios](https://github.com/Itachi1902a?tab=repositories)

---

### 📷 Prototipo ESP32-CAM — Integración de hardware

Prototipo electrónico basado en ESP32-CAM, pensado para integrar captura de imagen, señalización y comunicación.

- Módulo ESP32-CAM.
- Integración física de buzzer y pantalla LCD.
- Diseño de una carcasa para el circuito y alimentación.
- Exploración de notificaciones y comunicación con una aplicación.

**Tecnologías:** ESP32-CAM · Electrónica · IoT · Programación de microcontroladores
